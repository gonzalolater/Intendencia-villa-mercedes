# Guía de Contribución - Intendencia Villa Mercedes

¡Gracias por tu interés en contribuir al proyecto **Intendencia Villa Mercedes**! Valoramos mucho cualquier aporte de la comunidad, ya sea reportando errores, sugiriendo mejoras o enviando código.

Antes de comenzar, por favor revisa nuestro [Código de Conducta](CODE_OF_CONDUCT.md) para mantener un entorno colaborativo y respetuoso.

---

## 🛠️ Stack Tecnológico

Este proyecto está construido principalmente con:
* **TypeScript**
* **Vite**
* **Node.js / npm**

---

## 🚀 Cómo empezar

Para configurar el entorno de desarrollo local, sigue estos pasos:

1. **Haz un Fork** de este repositorio en tu cuenta de GitHub.
2. **Clona** tu fork en tu máquina local:
   ```bash
   git clone [https://github.com/TU_USUARIO/Intendencia-villa-mercedes.git](https://github.com/TU_USUARIO/Intendencia-villa-mercedes.git)
   cd Intendencia-villa-mercedes
