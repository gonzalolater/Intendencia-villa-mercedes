## 🚀 Stack Tecnológico y Arquitectura

El desarrollo prioriza un código limpio, minimalista y de alto rendimiento, evitando dependencias innecesarias para garantizar máxima estabilidad y velocidad de carga:

* **Framework UI:** React
* **Lenguaje:** JavaScript / TypeScript
* **Empaquetador:** Vite
* **Estilos:** CSS3 nativo (`src/styles.css`)

---

## 📋 Propuestas y Ejes Estructurales

El sitio expone los pilares fundamentales del plan de gobierno técnico y administrativo:

1. **Proyecto AET (Aqua Electric Technology):** Infraestructura y soberanía hídrica, blockchain provincial, wallet virtual, criptomoneda estable y energía renovable carbono-neutral.
2. **SLAT (Sistema / Wallet Digital):** Arquitectura Web3, gestión de activos digitales y finanzas descentralizadas.
3. **Ciudadano Tecnológico de Primer Nivel:** Marco de gobernanza digital e IA para la interacción cívica con la administración pública.
4. **Orquestación de Denuncias con IA (SISTEM-A):** Triaje inteligente, clasificación de casos y scoring dinámico de riesgo para la fiscalía.
5. **Auditoría, Flujos y Ciberseguridad:** Protocolos de grado militar, análisis de vulnerabilidades y blindaje de sistemas críticos.
6. **Reducción de Averiguación de Antecedentes a 5 Horas:** Automatización integral de validaciones policiales y judiciales.

## 🛠️ Desarrollo Local

### Requisitos previos
Asegurate de tener instalado en tu entorno:
* **Node.js** (versión recomendada 18+ o superior)
* **npm**

### Instalación

Cloná el repositorio e instalá las dependencias:

```bash
git clone [https://github.com/tu-usuario/intendencia-villa-mercedes.git](https://github.com/tu-usuario/intendencia-villa-mercedes.git)
cd intendencia-villa-mercedes
npm install
