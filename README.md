# Intendencia Villa Mercedes

Sitio web de campaña 2027 para la intendencia de Villa Mercedes, de Gonzalo
Daniel Aguilar.

## Desarrollo local

Requisitos: Node.js y npm.

```sh
npm install
npm run dev
```

Para generar y previsualizar la versión de producción:

```sh
npm run build
npm run preview
```

La aplicación está hecha con React, JavaScript, TypeScript y Vite. El contenido
principal se encuentra en `src/home.jsx` y los estilos en `src/styles.css`.
